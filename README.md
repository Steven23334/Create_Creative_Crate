# Creative Crate

[![Available on GitHub](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1)](https://github.com/Steven23334/Create_Creative_Crate)

A lightweight Create addon that adds a **Creative Crate** — a configurable infinite item source. Bind any item to it, and it will supply that item forever. Perfect for testing, building, and contraption prototyping.

## 📦 New Content

- **Creative Crate**
  Right-click the block with any item to bind it as the crate's template. The crate will then supply that item infinitely to anything that extracts from it — funnels, chutes, contraption inventories, etc. The bound item floats above the crate for easy identification.

- **In-world Binding**
  No GUI, no menus. Just right-click with the item you want. A chat message confirms the binding, and the crate updates immediately on both client and server.

- **On-block Display**
  The currently bound item is rendered floating just above the crate's top face, so you can tell at a glance what each crate is supplying. Look directly at the crate to reveal a highlight frame around the bound item.

- **Contraption Support**
  Works like a normal container. Mounted on a contraption, it keeps supplying its bound item, making it ideal for testing moving machines.

## 🎯 Purpose

- Provides an infinite, configurable item source without needing commands or creative tabs.
- Ideal for contraption testing, redstone prototyping, and pack development.
- Keeps the workflow in-world: bind, extract, done.

## 🔧 Installation

1. Make sure **NeoForge 1.21.1** is installed.
2. Install **Create** and its dependencies.
3. Place the `.jar` file of this mod into the `.minecraft/mods` folder.
4. Launch the game.

## ⚙️ Configuration

No configuration file is required. The bound item is stored in the block entity's NBT and persists across world reloads.

## ⚠️ Requirements

- **Minecraft Versions**: 1.21.1
- **Required Mod Loader**: [NeoForge](https://neoforged.net/) 21.1.188 or higher
- **Mod dependencies**: [Steven's Mod API](https://modrinth.com/project/ZfeSnlBx)

# 创造板条箱

[![可在 GitHub 上获取](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1)](https://github.com/Steven23334/Create_Creative_Crate)

一个轻量的机械动力附属模组，添加了 **创造板条箱** —— 一个可配置的无限物品源。绑定任意物品后，它会无限供应这个物品，适合测试、建造与装置原型开发。

## 📦 新增内容

- **创造板条箱**  
  手持任意物品右键方块，即可把它绑定为板条箱的模板。之后板条箱会无限供应这个物品，漏斗、溜槽、装置库存等任何抽取方式都能生效。绑定的物品会悬浮在板条箱上方，方便辨认。

- **世界内绑定**  
  没有 GUI，没有菜单。手持物品右键即可，聊天栏会给出绑定提示，且客户端与服务端会立即同步。

- **方块上方显示**  
  当前绑定的物品会悬浮渲染在板条箱顶面上方，一眼就能看出每个板条箱在供应什么。准星指向板条箱时，会在绑定物品周围显示一个高亮框。

- **装置支持**  
  行为与普通容器一致。装在装置上时，它会继续供应绑定的物品，非常适合测试移动机器。

## 🎯 模组用途

- 无需命令或创造模式标签页，即可获得可配置的无限物品源。
- 适合装置测试、红石原型与整合包开发。
- 全程在游戏内完成：绑定、抽取、结束。

## 🔧 安装方法

1. 确保已安装 **NeoForge 1.21.1**。
2. 安装 **机械动力** 及其前置。
3. 将本模组的 `.jar` 文件放入 `.minecraft/mods` 文件夹。
4. 启动游戏即可。

## ⚙️ 配置

无需配置文件。绑定物品保存在方块实体的 NBT 中，重载世界后依然保留。
